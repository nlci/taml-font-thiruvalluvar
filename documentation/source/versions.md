## Current version

The latest released version of the fonts is always available from the [ThiruValluvar release page](https://github.com/nlci/taml-font-thiruvalluvar/releases) as a .zip archive for all major platforms.

In addition to released versions, the most recent [development build](https://github.com/nlci/taml-font-thiruvalluvar/releases/tag/dev) is also on the release page.

## Previous versions

Previous versions remain available from the [release page](https://github.com/nlci/taml-font-thiruvalluvar/releases).

## Change history

A detailed list of changes for each version of the fonts is on the [Version history page](history.md).
